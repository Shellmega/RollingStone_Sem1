# 山区滚石模拟：弹性阻挡体增量

在现有凸多边形和参数化地形代码上增加了水平单自由度弹簧阻尼挡板，重点计算数值，不模拟网格局部变形。两份 `rollingstone.cpp` 已同步；推荐从仓库根目录的 `RollingStone.sln` 或构建脚本进入。

## 运行

需要 Windows、Visual Studio C++ 桌面工具和对应的 EasyX x64。推荐使用脚本，自动寻找本机 MSVC，避免 VS Code 中遗留的 MinGW 路径。

```bat
build_msvc.cmd --run
build_msvc.cmd --test
build_msvc.cmd --demo
```

也可双击 `run.cmd`。原有 `.sln` 使用 v143；如果本机只有新工具集，可在 VS 中重定向，或直接用上述脚本。EasyX 安装在自定义目录时，先设置 `EASYX_INCLUDE` 和 `EASYX_LIB`。

## 新按键

| 按键 | 功能 |
| --- | --- |
| B | 设置挡板位置、高度、质量、刚度、阻尼，随后重跑 |
| V | 开关挡板，使用同一块石头和相同初始状态重跑 |
| E | 导出当前轨迹、汇总结果、完整参数三个 CSV |
| R / G / T / M | 原有新石头、形状、地形、物理参数功能 |

模拟结束会自动导出到工作目录下的 `results/`。脚本运行时该目录在仓库根目录。修改地表物理参数会重新开始记录，避免同一条轨迹混用参数。改变地形会重新安装挡板；挡板默认在地形右端前12米。

## 模型与数值口径

挡板具有水平位移 q 和速度 v，满足 `M*q'' + c*q' + k*q = F_contact`。底部高程在安装时固定，竖直自由度由支座约束。它是单面、有限高度的等效缓冲挡板，不是连续弹性体、有限元网或可断裂结构。

- 多边形按实际边、顶点和挡板高度裁剪检测，包含边穿过挡板端点的情况。
- 接触速度使用双方相对速度，有效质量包含石头平动、转动及挡板水平运动。
- 作用冲量同时更新石头和挡板；偏心碰撞产生转动。
- 挡板接触恢复系数为0，摩擦系数为0.3；弹性回弹由支座弹簧产生。地面仍使用原有参数。
- 弹簧阻尼采用后向 Euler，分别累计物理阻尼耗能、积分数值耗散、接触耗能，不将数值耗散冒充材料耗能。
- 支座力是 `k*q + c*v`；CSV 的接触峰值是**子步平均冲量力**，随时间步改变，不能当作真实瞬时冲击峰值或直接用于结构设计。
- 耗能列仅覆盖挡板相关项，未汇总地面摩擦、空气阻力等全部损失，因此不能直接用于全程总能量平衡。
- `blocked_at_rest` 表示发生接触后、未通过挡板且最终石头和挡板基本静止；`passed_barrier` 表示石头完整通过挡板所在位置。接触一次不会直接算拦截成功。
- 极端高刚度、低质量、细薄石头可能超过允许子步数量，此时停止并记录错误，不伪造有效结果。参数是演示用等效值，尚未用真实拦截设施标定。

## 已验证的结果

`--self-test` 包含原有测试与新增弹性挡板测试。新增检查包括：弹簧阻尼能量恒等式；中心碰撞动量与耗能解析解；偏心冲量；有限高度接触和越顶通过；耦合能量；禁用挡板与旧算法一致；拦截；高速接触；时间步收敛。

2026-11-11 本机 MSVC x64 Release 实测：

| 平地对照算例 | 最大挡板位移 | 最终石头位置 |
| --- | ---: | ---: |
| 关闭挡板 | 0 m | 49.935664 m |
| k=500000 N/m，c=30000 N·s/m | 0.671827 m | 2.530084 m |
| k=1000000 N/m，c不变 | 0.515700 m | 0.423369 m |

三组均为同一正方形石头：质量5200 kg、初速度12 m/s、平地、初始x=1 m；挡板x=8 m、高6 m、质量2000 kg；模拟12秒。该算例用于验证挡板，不代表原始山坡的统计结果。运行 `--barrier-demo` 可重新生成全部数据。

外层时间步0.002、0.001、0.0005秒时，最大位移分别为0.671827、0.679280、0.683038米；粗细两组相对差1.64132%。空中耦合能量测试最大核算残差0.026348%，包含原有重力积分的数值耗散。以上是数值近似及有限测试证据，不代表任意参数都精确。

参考 CSV 位于 `examples/barrier_reference/`，包含每组 trajectory、summary、config。配置中记录石头局部顶点、质量、惯量、地形点、初始状态与实际物理参数。
