# 第二轮代码与运行复查 · 2026-11-13

## 本轮修改

| 问题 | 修改位置 | 修复后的行为 |
| --- | --- | --- |
| Tab 切换后新字段再次处理同一帧按键，焦点连续跳转 | `src3d/ui/widgets.h/.cpp` | 每帧仅一个输入框消费键盘输入；Tab/Shift+Tab逐个移动，禁用字段不进入焦点顺序 |
| 窄窗口时间轴控件超出可用宽度，实时跟随按钮可能覆盖其他控件 | `src3d/ui/app_impl.h`、`app.cpp`、`app_analysis.cpp` | 使用同一个宽度判断，窄窗口工具栏分两行，底部时间轴增高40像素 |
| 输入试验编号按回车无效，原分支含恒假条件 `&&false` | `src3d/ui/widgets.h`、`app_analysis.cpp` | 当前编号框按回车可选中已记录试验；0、超出范围和不能完整解析的编号显示提示 |
| F1 在快捷键处理处打开帮助，又被帮助绘制处立即关闭 | `src3d/ui/app.cpp`、`app_chrome.cpp` | F1集中切换帮助状态；帮助内Esc关闭；F12也可以截取帮助画面 |
| 提示气泡仍按旧时间轴高度定位 | `src3d/ui/app_chrome.cpp` | 根据实际底栏位置定位，避免遮住增高后的工具栏；同步修正帮助文字 |
| raylib内置F12与自定义截图同时触发，重复生成根目录截图，重启后可能覆盖旧图 | `src3d/cmake/Graphics.cmake`、`scripts3d/verify_release.py` | 关闭raylib内置自动截图，保留程序支持中文路径的截图流程；增加根目录截图不变的验收检查 |

本轮修改界面输入和布局，未改变物理模型、随机流或求解步长。删除了失效的恒假判断与空的字段变更分支。

## 运行验证

- 最终发布程序以 Release 编译，并在无 VS/SDK 开发环境变量、PATH 仅含 Windows 系统目录的进程中执行验收。
- 最终 exe 的22项随包自检全部通过，包含几何、物理、统计、存档/回放、UI模型、CLI和弹性挡板/组合场景测试。
- 相同种子 N=2 的 GUI 与 headless 物理结果一致，7个确定性 CSV 逐字节相同；中文和空格路径可写入；只读打开 `physics_updates=0`；数值回放通过。
- 实际键盘/鼠标输入：N从2改为3、批次种子改为77，Tab与Shift+Tab逐个切换；正式输出确认N=3、种子77、正常完成3次。
