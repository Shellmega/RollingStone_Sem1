# 山区滚石模拟 · RollingStone3D

更新日期：2026-11-13，第二轮复查版。程序、字体、纹理、场景与自检工具均已随包提供。

## 1. 直接运行

完整解压后，双击 **RollingStone3D.exe**。也可以双击以下启动文件：

| 文件 | 打开的场景 |
| --- | --- |
| run_3d.cmd | 默认山坡场景 |
| run_elastic_3d.cmd | 参数化山坡与弹性挡板 |
| run_obstacles_3d.cmd | 固定障碍与弹性挡板组合场景 |

运行要求：Windows 10/11 x64，显卡支持 OpenGL 3.3。运行发布包无需安装 Visual Studio，也不用重新编译。请让 `assets`、`configs3d` 与 exe 保持在同一文件夹；不要只把 exe 单独发给组员。

## 2. 第一次使用，按这个顺序操作

1. 打开“场景”页。左侧各组可以展开，修改地形、石块、初始条件、地表、挡板、固定障碍、统计及输出设置。鼠标滚轮滚动左侧参数区；鼠标停在参数名称上可看提示。
2. 修改后会出现黄色“待应用”标记。点击底部“应用”；红色提示代表参数不合法，需要先修正。运行时参数暂时锁定。
3. 切换到“运行”页。先点“运行单次试验”观察当前预览石块；单次试验使用“预览种子”，不消耗批次种子。
4. 正式统计时，先用 N=10 调试，再增加次数。设置“批次数 N”和“批次种子”，选择“后台全速”可以直接计算；“前两次”会先实时预览。点击“开始批量计算”；若还有待应用参数，按钮会显示“应用并开始批量计算”。
5. 等待计算与文件保存结束，再到“分析”页查看路径频率、首次触板及坡脚分布。左侧点击试验列表，或输入已记录的试验编号后按回车/点“转到”。底部时间轴支持播放、暂停、速度选择、拖动与首次触板定位。
6. 结果默认保存在 `results3d/run_…`。在“分析”页点“打开结果…”可重新打开保存的结果；这是只读查看。需要重新改参数时，在“场景”页点“返回场景编辑”。

复现实验时，应保持配置、批次种子、程序版本和依赖版本一致；预览石块与批量中的第一个随机石块不必相同。

## 3. 常用操作

| 操作 | 方法 |
| --- | --- |
| 旋转、平移、缩放三维视图 | 左键拖动；右键/中键拖动；视图中滚动滚轮 |
| 透视、俯视、侧视、跟随 | 数字键 1 / 2 / 3 / 4，或点击视图左上角 |
| 切换输入框 | 输入框中按 Tab / Shift+Tab；不可用的输入框不参与切换 |
| 切换场景/运行/分析页 | 未编辑输入框时按 Tab / Shift+Tab，或直接点击顶部标签 |
| 提交输入、放弃本次输入 | 回车结束编辑；Esc 恢复该输入框开始编辑前的值 |
| 应用参数 | 点击“应用”；未编辑输入框时可用 Ctrl+Enter |
| 保存配置、打开结果 | Ctrl+S / Ctrl+O（未编辑输入框时） |
| 暂停计算、播放/暂停回放 | 运行页/分析页分别按空格（未编辑输入框时） |
| 逐帧、换试验、首次触板 | 分析页 ← / →、↑ / ↓、E（未编辑输入框时） |
| 帮助 | F1 打开，再按 F1 或 Esc 关闭 |
| 截图 | F12，默认保存到 `screenshots/screenshot_时间戳.png`；显式指定 `--shots` 时使用固定文件名 |
| 演示模式 | F5；Esc 退出 |

窄窗口下，回放工具栏自动分两行，触板按钮和开关仍可操作。

## 4. 怎样判断结果可用

- 石块是随机凸多面体，显示为有棱角的不规则石块，符合凸多面体模拟的设定。r/V/顶点数控制几何形状；仅凭外观不能判断计算是否正确。
- 石块停在坡面上可能与地表摩擦、滚阻、初速度、释放位置及石块形状有关。需要做参数对照，不能直接把静止都判为故障。
- `status=complete` 表示批次文件已提交。正式概率还需要所有计划试验正常结束；请同时看失败、超时、取消及已完成数。`cancelled`、`.pending`、`INCOMPLETE.txt` 不能当作完整概率结果。
- 完整批频率为 H/N；同一试验经过同一格只计一次。各格频率不能直接相加当作总概率。“首次触板”的条件概率使用触板试验数 B 作为分母。
- 超时不等于程序崩溃。“单次时间上限”最大 60 s；到上限仍未满足结束条件会记为 timeout，正式概率受到影响。
- 弹性挡板采用沿法线方向运动的质量—弹簧—阻尼模型。板的位置和回弹来自数值求解，板面保持刚性；这不是柔性网格/薄板弯曲模型。力学口径与限制见 [弹性挡板说明](docs/ELASTIC_BARRIER.md)。

## 6. 自检与命令行

在本文件夹空白处打开终端，可执行：

```powershell
.\run_3d.cmd --help
.\run_3d.cmd --self-test
.\run_3d.cmd --config configs3d/batch_throughput.ini --batch 2 --seed 2026 --preview 0 --headless --output results3d_check
.\run_3d.cmd --view-results "results3d\某次运行目录"
```

`batch_throughput.ini` 是水平面稳定基准，用于快速验证，不是山坡演示。随包测试工具位于 `selftests`，请保留整个文件夹。`package-sha256.json` 记录发布文件哈希；用户自行产生的 `results3d` 和截图不在发布文件清单内。
